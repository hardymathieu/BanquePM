Installer ta propre banque

Tu peux héberger ta propre Banque de papa et maman, pour ta famille et des amis, sur un compte Cloudflare gratuit. Compte cinq minutes. Si quelqu'un l'héberge déjà pour toi, demande plutôt une invitation.

Ce qu'il te faut

  • Un compte Cloudflare (gratuit). Le plan gratuit suffit très largement : une famille fait quelques dizaines de requêtes par jour, sur 100 000 permises.
  • Un compte GitHub (gratuit) : le bouton y copie le code de l'app.
  • Un gestionnaire de mots de passe, pour ton mot de passe d'administration.

Les étapes

1. Le bouton « Deploy to Cloudflare »

Ouvre Deploy to Cloudflare (le même bouton est en haut du README). Connecte ton compte Cloudflare et ton compte GitHub, puis garde le nom proposé ou choisis-en un : il fera partie de l'adresse de ta banque.

2. Le mot de passe d'administration (ADMIN_TOKEN)

Le formulaire te demande ADMIN_TOKEN. Choisis un long mot de passe aléatoire, de 32 caractères ou plus, généré par ton gestionnaire de mots de passe, et range-le dedans. Sur un ordinateur, openssl rand -base64 32 en fabrique un.

Ce mot de passe sert seulement à créer des invitations. Il ne donne accès à aucune banque, pas même la tienne.

3. Laisse Cloudflare travailler

Cloudflare copie le code dans ton GitHub, crée la base de données, construit l'app et la publie. Ça prend une à deux minutes. À la fin, tu obtiens une adresse comme https://banque-papa-maman.ton-compte.workers.dev.

4. Crée ta banque

Ouvre https://…workers.dev/admin, colle ton ADMIN_TOKEN, puis touche Créer ma banque. Continue avec le guide Créer la banque de ton enfant.

Pour des amis : sur la même page, Créer une invitation, puis envoie le lien (voir Invitation).

Ce que tu vois, et ce que tu ne vois pas

Depuis le tableau de bord Cloudflare, tu ne peux lire aucune banque, pas même la tienne : la base ne contient que des fichiers chiffrés, des identifiants tirés au hasard, des numéros de version et le mois du dernier changement. Les journaux et les statistiques sont coupés dans la configuration (wrangler.jsonc). Cloudflare transporte le trafic et voit donc passer les adresses IP, comme tout hébergeur. Le détail est sur la page /confidentialite de ta banque.

Réglages facultatifs

  • Un contact sur la page de confidentialité : dans Cloudflare, ouvre ton Worker → Settings → Variables and Secrets, et ajoute INSTANCE_CONTACT (par exemple une adresse e-mail).
  • Ton propre nom de domaine : dans ton Worker → Settings → Domains & Routes → ajoute un domaine géré par Cloudflare. Attention : changer d'adresse change aussi les liens. Fais-le avant de créer les banques.
  • Mot de passe d'administration perdu : remplace la valeur d'ADMIN_TOKEN dans Variables and Secrets. Les banques ne sont pas touchées.

Mettre à jour

Le bouton a créé une copie du code dans ton GitHub. Elle ne se met pas à jour toute seule. Pour récupérer les nouveautés, sur un ordinateur :

git clone https://github.com/ton-compte/ta-copie.git
cd ta-copie
./scripts/update-from-upstream.sh
git push

Cloudflare reconstruit et republie tout seul après le git push. Une nouvelle version lit toujours les banques existantes.

Ne supprime jamais la ligne database_id dans wrangler.jsonc de ta copie. C'est elle qui relie l'app à ta base de données ; sans elle, un déploiement pourrait créer une base vide. Le script de mise à jour la garde pour toi.

Tout arrêter

Supprimer le Worker et la base de données D1 dans Cloudflare efface toutes les banques de ton serveur. Préviens les familles invitées pour qu'elles téléchargent une sauvegarde avant.
