Demander une invitation

Si quelqu'un que tu connais héberge déjà une Banque de papa et maman, tu n'as rien à installer : il te suffit d'un code d'invitation. Sinon, installe ta propre banque.

Ce que tu demandes, et ce que tu ne donnes pas

Demande simplement à l'hébergeur « une invitation pour la Banque de papa et maman ». Il n'a besoin de rien savoir d'autre : ni le prénom de ton enfant, ni son âge, ni ton e-mail. Même après, il ne pourra jamais lire ta banque, qui est chiffrée sur ton téléphone.

Ce que tu reçois

Un lien qui ressemble à https://…/#i=ABCDE-23456, ou juste le code ABCDE-23456, parfois sous forme de QR code.

  • L'invitation ne sert qu'une seule fois.
  • Elle est valable 7, 14 ou 30 jours (l'hébergeur choisit).
  • Les majuscules et le tiret ne comptent pas : abcde23456 marche aussi.

Utiliser l'invitation

  1. Avec le lien : ouvre-le sur ton téléphone. La page « Crée la banque de ton enfant » s'ouvre, le code déjà rempli.
  2. Avec le code seulement : ouvre l'adresse de la banque, touche J'ai une invitation, puis tape le code.

Ensuite, suis le guide Créer la banque de ton enfant.

Si ça ne marche pas

« Cette invitation n'est plus valable. Demande-en une nouvelle. »Le code a déjà servi, ou il a expiré. Demande un nouveau code à l'hébergeur.
« Un code a 10 caractères… »Il manque un caractère ou il y en a un de trop. Les lettres I et O et les chiffres 0 et 1 n'existent pas dans les codes : c'est sûrement un 1 ou un 0 mal lu.

Si tu es l'hébergeur

  1. Ouvre https://ta-banque…/admin.
  2. Colle ton mot de passe d'administration (ADMIN_TOKEN). Il reste dans la page, il n'est enregistré nulle part.
  3. Choisis la durée, touche Créer une invitation, puis envoie le lien, le code ou le QR code.

La page d'administration ne permet de lire aucune banque. Elle sert seulement à créer des invitations, et à créer ta propre banque avec Créer ma banque.
